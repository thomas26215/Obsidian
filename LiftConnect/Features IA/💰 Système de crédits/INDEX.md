# 💰 Système de crédits IA — LiftConnect

Monétisation intelligent basée sur consommation IA réelle avec flexibilité totale pour l'utilisateur.

---

## 📋 Vue d'ensemble

Le système fonctionne sur **deux types de crédits** :
- **Crédits abonnement** : Renouvelés mensuel, expirents fin du mois
- **Crédits bonus** : Achetés une fois, gardés indéfiniment

Chaque utilisation IA consomme des crédits proportionnels à sa complexité (tokens/compute réels).

## 🎯 Ratios clés

```
Abonnement : 1 crédit ≈ 0,033€ (meilleur prix)
Bonus petit : 1 crédit ≈ 0,0745€ (2.25x plus cher)
Bonus moyen : 1 crédit ≈ 0,0698€ (2.1x plus cher)
Bonus grand : 1 crédit ≈ 0,0649€ (2x plus cher)
```

**Stratégie** : L'utilisateur préfère l'abonnement pour économiser, mais crédits abonnement créent urgence (expiration). Bonus = flexibilité pour gros usages.
