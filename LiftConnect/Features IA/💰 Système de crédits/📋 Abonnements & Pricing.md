## 🎯 Ratio de prix

```
Crédits ABONNEMENT (meilleur prix)
  → 0,99€ = 30 crédits = 0,033€/crédit ⭐

Crédits BONUS (plus cher intentionnellement)
  → 1,49€ = 20 crédits = 0,0745€/crédit
  → 3,49€ = 50 crédits = 0,0698€/crédit
  → 6,49€ = 100 crédits = 0,0649€/crédit

Ratio : Abonnement est 2-2.25x moins cher que bonus
Psychologie : Incite l'utilisateur à prendre l'abonnement plutôt que bonus isolé
```

## 🔄 Auto-achat bonus (optionnel)

Utilisateur configure à chaque renouvellement d'abonnement :
- **Quantité** : 10, 20, 50, ou 100 crédits
- **Prix** : Automatiquement facturé au prix bonus
- **Récurrence** : Chaque renouvellement d'abonnement
- **Crédits achetés** : Gardés indéfiniment, s'accumulent

### Exemple

```
Abonnement Analyse (0,99€/mois)
+ Auto-achat 20 crédits (1,49€/mois)
= 2,48€/mois total

Crédits abonnement : expirents chaque mois
Crédits bonus : s'accumulent indéfiniment
```
